# asas-do-sert-o-
Asas do sertão é um jogo de arcade estilo Flappy Bird com temática do sertão, programado em Python com a libraria Pygames


Requisitos:

• pygame 2.6.0

• python 3.12.3 (versões mais recentes não funcionam)
